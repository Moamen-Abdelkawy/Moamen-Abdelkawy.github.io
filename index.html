Projects

Panamax freight rate forecasting

MSc capstone, WorldQuant University · Presented at the 14th General Assembly, Arab Federation of Shipping (AFOS)

Six multi-horizon XGBoost models forecasting Transatlantic (P1A_82) and Transpacific (P3A_82) dry bulk freight rates 1, 2, and 4 weeks ahead, built on 245 features engineered from 701 Baltic Exchange, Clarksons, and bunker indicators. Guided by basin-arbitrage dynamics—ranked second overall in feature importance—we identified a systematic 5–7 day timing bias from bilateral broker reporting lags and corrected it with phase-shift calibration.

International trade flow analyzer

A Python tool for bilateral trade analysis that combines harmonized BACI data (1995–2024) with the live UN COMTRADE API (1962–present). It has an interactive command-line interface, fuzzy country matching, multi-level HS code support, professional visualizations, and comprehensive data exports for researchers, policy analysts, and trade professionals.

Multi-asset deep learning trading

Single-output and multi-output LSTM models that predict 25-day returns for five ETFs across equities, bonds, gold, and oil. The predictions drive long-short strategies that outperformed buy-and-hold benchmarks on risk-adjusted returns in backtests, and the project also covers tactical asset allocation.

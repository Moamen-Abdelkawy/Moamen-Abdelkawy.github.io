Source for my professional profile at [moamen-abdelkawy.github.io](https://moamen-abdelkawy.github.io).

I'm a Senior Economic Analyst at National Navigation Company in Cairo. ## Updating the page

All content is plain HTML in `index.html`, so no build step is needed.

- **New role:** copy an `<li class="role">` block in the Experience section. Move the `role--current` class to the newest role so its marker stays highlighted.
- **New article or project:** copy an existing `<li>` in the Writing section or an `<article class="project">` block in Projects.
- **New résumé:** upload the new PDF with the same filename (`Moamen_Abdelkawy_Resume.pdf`).

The fan chart at the top of the page is a decorative illustration of a forecast, not real market data.
